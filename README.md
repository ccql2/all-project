# 项目作品集

这里记录了我从学习到独立开发的代码项目。

我的学习路径大致是：
**观察现象 → 产生想法 → 落地实现**

每个项目都是我在不同阶段的尝试。早期以学习和借鉴为主，后期逐渐过渡到自己设计和实现。

## 项目列表

### 1. 轮式足球机器人（soccer_robot）
早期入门项目，在已有框架上尝试加入自己的功能，属于学习阶段的实践，这个项目参加比赛获国家级三等奖。

### 2. 井盖隐患识别（yolov5-master）
基于YOLOv5的学习项目，针对井盖隐患识别场景做了调整和功能扩展，简历中提到的枣树叶片病害识别项目是在这个项目落地后进行的实践项目，成功立项省级大创项目，代码不便公开。

### 3. 垃圾分类（rubbish-category）
第一次尝试自己组织一个完整项目。参考和借鉴了较多开源资料，在摸索中完成了数据处理、模型训练、改进到识别、优化的全流程。这个阶段我从“能看懂代码”过渡到了“能改代码、搭流程”。

### 4. wx_chili
源于自己的一个想法，通过搜集资料、借鉴代码，再进行拼接、改进和调试，最终实现了预期功能。

### 5. 医学图像识别项目（暂不公开）
目前最重要的项目。基于社会现状分析问题，在现有模型上提出改进方案，并完成了消融实验和对比实验，验证了改进后模型的优势。相关论文正在投稿中，代码暂时不便公开，在这个项目的基础上新增安防部分功能后作为我的毕设项目。
